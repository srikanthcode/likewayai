# Code Error Analysis Plan

## User Request
User wants to "analys a code find all errors in code" — comprehensive error analysis of the Likeway AI codebase.

## Phase 1: Exploration Results

### Critical Issues Already Identified
1. **SECURITY: `.env.local` contains live secrets** — All API keys, database credentials, OAuth secrets, and payment gateway credentials are exposed. Must rotate immediately.
2. **Inconsistent DB_NAME defaults** — `memory.ts` falls back to `"zynthex_ai"` while all other modules use `"likeway_ai"`. Copy-paste error from older project.
3. **`setInterval` in serverless environment** — `rate-limit.ts` uses `setInterval` which accumulates in Vercel serverless.
4. **Missing guest auth route** — `AuthProvider.tsx` calls `POST /api/auth/guest` but no route file exists.
5. **Legacy localStorage key** — `gemma_userId` leftover from previous project.
6. **Monolithic `page.tsx`** — 2000+ lines, maintainability concern.
7. **Duplicate rate limiting** — Two separate implementations, one unused.
