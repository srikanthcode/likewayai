# Plan: Enhance Premium Plan (₹799 Plus) UI + Playwright E2E Tests

## Overview

The Likeway AI codebase already has a complete pricing system with 4 tiers. This plan enhances the **Plus (₹799)** plan to look more premium/appealing, and adds Playwright E2E tests for production readiness.

---

## Part 1: Enhance Plus (₹799) Plan UI

### 1.1 Update `src/lib/plans.ts`
- Add optional `badge` field to `Plan` interface
- Set `badge: "MOST POPULAR"` on Plus plan
- Rewrite Plus features to be more compelling:
  - "10 premium models including GPT-4o & Claude"
  - "Architect Coding Agent for 50+ languages"
  - "Deep Research with autonomous web analysis"
  - "Advanced vision — analyze screenshots & diagrams"
  - "AI-powered image generation"
  - "Custom instructions & persistent memory"
  - "Priority response queue"

### 1.2 Update `src/app/pricing/page.tsx` — Make Plus card dominant
- **Add badge**: "MOST POPULAR" gradient badge (blue-indigo-violet) above Plus card
- **Upgrade card styling**: Stronger border (`border-blue-500/50`), ring (`ring-1 ring-blue-500/30`), gradient background (`from-[#0a1430]`), stronger glow (`shadow-[0_0_50px_rgba(59,130,246,0.2)]`)
- **Upgrade CTA button**: Change from outline to full gradient (`bg-gradient-to-r from-blue-500 to-indigo-500`)
- **Add Sparkles icon** next to Plus plan name
- **Scale up card**: Add `md:scale-[1.02] z-10` to make Plus card slightly larger

### 1.3 Update `src/components/PricingModal.tsx` — Modal parity
- Update badges: Plus → "MOST POPULAR", Go → "LIMITED OFFER", Pro → "BEST VALUE"
- Change Plus color from `#8B5CF6` (violet) to `#6366F1` (indigo) to distinguish from Pro
- Add highlight ring to Plus card in modal

## Part 2: Playwright E2E Tests

### 2.1 Install Playwright
```bash
npm init playwright@latest
```

### 2.2 Create `playwright.config.ts`
- Test directory: `./e2e`
- Base URL: `http://localhost:3000`
- Web server: `npm run dev` on port 3000
- Chromium only for speed
- HTML reporter

### 2.3 Create `e2e/pricing.spec.ts` — Core pricing tests
- Loads and displays all 4 plans (Core, Go, Plus, Pro) with correct prices
- Plus plan has "MOST POPULAR" badge
- Go plan has "LIMITED TIME OFFER" badge
- Pro plan has "BEST VALUE" badge
- Plus card has visual emphasis (gradient background, stronger glow)
- "Upgrade to Plus" button is visible with gradient styling
- Feature highlights section visible (Coding Agent, Vision, Deep Research)
- Additional features grid shows all 8 items
- GST notice and footer visible

### 2.4 Create `e2e/checkout-flow.spec.ts` — Checkout interaction tests
- Clicking "Upgrade to Plus" without auth redirects to `/login`
- Clicking "Upgrade to Go" without auth redirects to `/login`
- Checkout overlay appears when authenticated (shows "Checkout" + "Secure Vault Protected")

### 2.5 Create `e2e/payment-api.spec.ts` — API route validation
- `POST /api/create-order` returns 401 without auth
- `POST /api/verify-payment` rejects invalid signatures
- `GET /api/user/plan` returns 401 without auth

### 2.6 Update `package.json`
Add scripts:
```json
"test:e2e": "playwright test",
"test:e2e:ui": "playwright test --ui",
"test:e2e:headed": "playwright test --headed"
```

### 2.7 Update `.gitignore`
Add test artifacts:
```
/test-results/
/playwright-report/
/blob-report/
/playwright/.cache/
```
